# Dhruva Windows

Dock nativa para Windows construída com **Tauri 2 + Rust + Svelte 5**. É um port independente, inspirado no **Dhruva** para GNOME Shell.

## Créditos

Este projeto é inspirado no **Dhruva**, a dock para GNOME Shell criada por **NarkAgni**:

- Projeto original: https://github.com/NarkAgni/dhruva
- Site oficial / instalação: https://extensions.gnome.org/extension/9495/dhruva/

O nome, a ideia e a identidade visual do Dhruva pertencem ao projeto original. O port Windows é uma implementação separada para a plataforma Windows.
